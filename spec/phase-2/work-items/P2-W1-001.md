# P2-W1-001 — Provider Connection Control Plane

Owner: Worker 1
Depends on: none

Implement vault-backed provider credential references, provider onboarding/activation state, ConnectedCapabilityInstance activation/deactivation, capability observations, credential rotation, provider activation records and safe operator controls.

Acceptance:
- no raw credential values enter Git, logs or protocol events;
- one vault reference can resolve a provider credential bundle;
- account/tenant/geography/currency/permission scope is explicit;
- capability state and source availability remain distinct;
- activation is impossible without successful authentication/eligibility evidence;
- historical provider activation records are immutable;
- provider failure cannot disable unrelated provider instances;
- phase-2 state is updated only by the TL after verified merges.
