# P2-W1-003 — Coverage-Gap Local Rail Program

Owner: Worker 1
Depends on: P2-W1-002, P2-W2-002, P2-W3-002

Implement the Coverage Gap Case workflow and direct-local-provider onboarding path.

Acceptance:
- every country/method/currency/direction gap can be represented;
- gaps are classified by regulatory, capability, commercial, capacity or reliability cause;
- the workflow selects the narrowest provider/rail integration needed;
- direct local connectors are independently certified;
- no "global coverage" claim can bypass the matrix;
- blocked/sanctioned/no-route cases are explicit.
