# P2-W2-001 — Stripe Production Connector

Owner: Worker 2
Depends on: P2-W1-001

Implement the real Stripe Connector using the v1.5 capability hierarchy and ProviderStateEnvelope.

Cover the enabled capabilities actually available on the connected account, including payment lifecycle, customer-action-required states, recurring, refunds/disputes, payout/external-funds observation, provider-native optimization and Stripe PayPal where eligible.

Acceptance:
- no Stripe SDK types leak into domain packages;
- real test/sandbox calls succeed where enabled;
- live account capability scope is observed rather than assumed;
- PaymentIntent-like asynchronous/customer-action/capture semantics are lossless;
- webhook signatures and replay/idempotency are verified;
- refunds/disputes reconcile;
- external balances are observations, not custody;
- direct PayPal is not conflated with Stripe PayPal;
- negative/unknown capability cases remain non-routable.
