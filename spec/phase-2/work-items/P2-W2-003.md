# P2-W2-003 — Cross-Provider Lifecycle and Conformance Certification

Owner: Worker 2
Depends on: P2-W1-003, P2-W2-002

Create the common certification suite across all production providers.

Acceptance:
- customer-action-required;
- async processing;
- capture;
- recurring mandate;
- refund;
- dispute;
- payout;
- duplicate submission;
- webhook loss;
- provider outage;
- UNKNOWN;
- provider revision change;
- fallback/re-authorization

are exercised for every applicable provider capability.

All providers share the same PaySwap authorization, evidence, reconciliation and security gates.
