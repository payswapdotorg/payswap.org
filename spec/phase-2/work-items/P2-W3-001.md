# P2-W3-001 — MTN MoMo, Flutterwave and Paystack Production Connectors

Owner: Worker 3
Depends on: P2-W1-001

Implement the real MTN MoMo, Flutterwave and Paystack Connectors using one provider-neutral adapter contract.

Cover actual account-enabled methods, mobile money, cards, bank/local methods, recurring where supported, refunds, webhooks and reconciliation.

Acceptance:
- exact live/test credential bundles resolve only from the vault;
- each provider has independent ConnectedCapabilityInstances;
- webhook verification is provider-correct;
- provider lifecycle and external IDs are preserved;
- unsupported country/method/currency/account states are honest;
- UNKNOWN and webhook loss reconcile;
- no provider-specific object becomes a domain primitive;
- each provider has positive, negative and unavailable/unknown conformance cases.
