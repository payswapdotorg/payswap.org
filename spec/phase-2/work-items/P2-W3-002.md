# P2-W3-002 — Adyen, Airwallex and EBANX Connectors

Owner: Worker 3
Depends on: P2-W2-001, P2-W3-001

Implement Adyen, Airwallex and EBANX connectors as provider-neutral implementations.

Acceptance:
- actual merchant/entity eligibility is observed;
- local payment methods and currencies are exposed only when enabled;
- payout and pay-in capabilities are distinct;
- webhook authentication and idempotency are verified;
- EBANX uses the current supported signing/authentication path;
- external funds positions remain observations;
- provider IDs/revisions/evidence are preserved.
