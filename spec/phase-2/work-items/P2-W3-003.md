# P2-W3-003 — Production Provider Rollout, Browser and Operator Verification

Owner: Worker 3
Depends on: P2-W1-003, P2-W2-003

Perform controlled production activation of certified providers and verify the operator/customer experience over real provider-backed paths.

Acceptance:
- provider activation is reproducible;
- preview/production parity remains explicit;
- provider health and coverage appear in Command Center;
- browser journeys use real API/protocol/provider paths;
- operator can distinguish provider failure, UNKNOWN, compliance block and NO_VIABLE_ROUTE;
- release record names connected providers and evidence;
- rollback/deactivation path is tested;
- provider secrets never appear in artifacts.
