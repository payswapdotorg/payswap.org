# P3-W1-002 — Authentication, Onboarding and Connection UX

Owner: Worker 1
Depends on: P3-W1-001, P3-W3-001

Implement real sign-in/onboarding and connection flows.

Acceptance:
- user identity/session flow is real and secure;
- provider connection supports delegated OAuth/connected accounts/scoped credentials;
- interactive browser/local-rail connection is supported where applicable;
- raw passwords/API keys/cookies/MFA material never reach model context;
- connection scope, authorization mode, expiry and reauth state are visible;
- connection never implies blanket withdrawal authority;
- browser journeys are tested end-to-end.
