# P3-W1-003 — Infrastructure Hardening and Free/Low-Cost Controls

Owner: Worker 1
Depends on: P3-W1-001, P3-W2-002, P3-W3-002

Harden the public app deployment and keep the initial stack free/low-cost.

Acceptance:
- Vercel public web deployment is production-ready;
- Neon production/preview separation is verified;
- Upstash usage has explicit namespace/command/rate budgets;
- R2 storage/egress/retention posture is explicit;
- Resend/Apify are absent unless actual workflow requirements justify them;
- no unexpected paid dependency;
- health/readiness, observability and rollback are verified;
- production deployment record is reproducible.
