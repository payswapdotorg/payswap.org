# P4-W1-002 — Wallet/Signer Authorization and Blockchain Security Kernel
Owner: worker-2
Dependencies: Phase 3 COMPLETE

Implement the trusted-surface boundary between intent preparation and user-controlled signing: authorization requests, signing requests, simulation results, expected balance/state deltas, scoped delegation, signer adapters and deterministic security gates.

Before authorization evaluate chain, asset, amount, destination, spender/approval changes, expiry, route and protocol/contract identity.

Supported consequential writes follow:
prepare → simulate when supported → deterministic policy/security → readable expected-state diff → authorization → immediate pre-broadcast recheck → broadcast.

No agent may directly broadcast or override security BLOCK. No raw private key, seed, wallet password, provider secret, cookie or MFA secret may enter agent context or ordinary artifacts. Delegation must be attenuated and revocable where supported. EIP-712/ERC-1271 semantics belong behind appropriate adapters.

Acceptance: adversarial negative tests, stale-state invalidation, simulation-never-authority tests and exact evidence.
