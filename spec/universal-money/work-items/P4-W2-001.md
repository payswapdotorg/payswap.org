# P4-W2-001 — Multi-Chain Adapter SDK
Owner: worker-1
Dependencies: P4-W1-001, P4-W1-002

Implement chain-family adapters behind provider-neutral contracts.

Initial families:
- EVM;
- Solana;
- UTXO.

Lifecycle:
observe → prepare → simulate → authorize → broadcast → observe → finality → reconcile → evidence.

Requirements:
- real testnet/provider proof where practical for each family;
- no single RPC/indexer/simulation vendor as a core dependency;
- fee, finality and reorg semantics explicit;
- UNKNOWN for ambiguous/unfinalized state;
- testnet/simulation cannot be production financial execution.

Acceptance: adapter contract + integration + failure/reconciliation tests and external provenance evidence.
