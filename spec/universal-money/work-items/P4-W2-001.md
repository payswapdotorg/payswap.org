# P4-W2-001 — Multi-Chain Adapter SDK
Owner: worker-1
Dependencies: P4-W1-001, P4-W1-002

Implement chain-family adapters behind the provider-neutral onchain capability contracts.

Initial implementation families:
- EVM;
- Solana;
- UTXO.

Lifecycle:
observe → prepare → simulate → authorize → broadcast → observe → finality → reconcile → evidence.

Requirements:
- at least one real testnet/provider proof where practical for each initial family;
- no core dependency on one RPC/indexer/simulation vendor;
- fee semantics explicit;
- finality/reorg behavior explicit;
- UNKNOWN used for ambiguous/unfinalized external state;
- testnet/simulation paths cannot be production financial rails.

Acceptance includes integration tests, failure/reconciliation tests, adapter contract tests and exact external evidence/provenance.
