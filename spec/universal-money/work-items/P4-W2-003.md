# P4-W2-003 — Merchant Crypto Checkout + Stripe Settlement
Owner: worker-3
Dependencies: P4-W1-003, P4-W2-001

Build the Stripe-class merchant workflow:
merchant onboarding → configure crypto acceptance → create payment → customer chooses crypto → wallet authorization → execution → finality → merchant status/webhook → settlement.

Support:
- PaymentIntent;
- CheckoutSession;
- wallet payment;
- webhooks;
- status/recovery;
- refunds where underlying rail supports them;
- settlement destination policy;
- Stripe connection.

Stripe modes are explicit:
NATIVE_STRIPE_CRYPTO and PAYSWAP_EXTERNAL_SETTLEMENT.

Acceptance:
- merchant UX remains fiat-denominated unless advanced details are opened;
- payment is not final before underlying evidence/finality;
- Stripe balance settlement is shown only when actual connected Stripe capability is eligible and executable;
- no fake payment success;
- browser/API end-to-end evidence recorded.
