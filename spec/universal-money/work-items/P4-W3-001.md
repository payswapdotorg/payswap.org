Extend Reality Engineering Lab so certified onchain capabilities participate in the existing Organization/Strategy/Capability search and simulation model.

- real capability contracts consumed, no shadow models;
- replay/fault tests cover chain/protocol failures and UNKNOWN;
- exact evidence recorded.
