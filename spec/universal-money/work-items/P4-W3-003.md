# P4-W3-003 — Adversarial Onchain Security + Threat Intelligence
Owner: worker-3
Dependencies: P4-W1-002, P4-W2-002

Extend the Security Immune System to blockchain-specific threats and add the adversarial transaction agent.

Threat families:
- malicious approvals/permits;
- unexpected spenders;
- token impersonation;
- honeypot/transfer restrictions;
- proxy/admin/implementation changes;
- oracle manipulation;
- bridge compromise;
- MEV/sandwich exposure;
- destination/chain confusion;
- replay/signature-domain issues;
- unexpected balance/state deltas;
- stale/materially changed simulations;
- finality/reorg anomalies.

Agent outputs threat signals with evidence and confidence. Deterministic policy remains authoritative:
ALLOW | ALLOW_WITH_CONSTRAINTS | REQUIRE_CONFIRMATION | BLOCK.

Acceptance:
- intentional malicious fixtures are blocked;
- security signals link to evidence;
- the agent cannot downgrade BLOCK;
- quarantine/restrict/retire flows integrate with SecurityAdvisory/ThreatSignature/SecurityEpoch.
