# P4-W4-001 — Mixed Fiat/Onchain Route Compiler
Owner: worker-1
Dependencies: P4-W3-001, P4-W3-002

Compile one canonical Money Movement Intent into multi-leg routes spanning fiat and onchain rails.

Prove representative routes:
- crypto → DEX → stablecoin → off-ramp → bank;
- fiat → PSP → stablecoin → chain → recipient;
- chain A → DEX → bridge → chain B;
- eligible crypto → native Stripe crypto settlement.

Every leg must preserve authorization lineage, provider/chain state, finality and evidence.

Failure at any leg must preserve UNKNOWN/reconciliation semantics. Provider-native paths remain candidate baselines.

Acceptance:
- no hidden custody;
- no duplicate ledger;
- deterministic route-plan tests;
- real integration evidence for supported journeys.
