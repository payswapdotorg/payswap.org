# UX-002 — Navigation model, state vocabulary and command grammar convergence (`@payswap/ux` + `@payswap/surface`)

Owner: dispatched implementation worker (Wave A, lane 2)
Depends on: UX contract set v1.1 (TL-reviewed — `spec/experience/contracts/TL-REVIEW-v1.md`)
Parallel with: UX-001 (disjoint file ownership: this item owns `packages/ux/**` and `packages/surface/**` ONLY)
Stage: directive §19 "Shared component system" (logic/vocabulary layer beneath the components)

## Scope

Converge the UX logic packages onto the governing contracts:
- `spec/experience/contracts/01-NAVIGATION-CONTRACT.md` (v1.1)
- `spec/experience/contracts/06-SEARCH-COMMAND-CONTRACT.md` (v1.1, incl. R2)
- `spec/experience/contracts/07-ERROR-STATE-CONTRACT.md` (v1.1)

Deliverables:
1. **Object-model navigation registry** (`packages/ux/src/product-ia.ts`): the normative sidebar taxonomy — 5 persistent rows (Home `/`, Balances `/balances`, Transactions `/transactions`, Customers `/customers`, Catalog `/catalog`) + workload groups (Accept, Bill, Insights, Capabilities, More) with their items per contract 01 §3; `data-testid` conventions (`nav.group.<slug>`); the create-menu item list with chords. **Roles become projections**: a role filters/emphasizes groups (and switches merchant/consumer projection), it NEVER re-axes the navigation. Existing `PRODUCT_ROLES`/`ROLE_NAV_CAPABILITIES` consumers keep working via a compatibility fold (role → emphasized-groups mapping), additive API.
2. **Eight-state outcome vocabulary bridge** (`packages/ux/src/honest-states.ts`): map `HonestStateView`/tones onto the contract's state set (`succeeded · processing · failed · refunded · partially_refunded · disputed · blocked · dropped`); UNKNOWN-outcome NEVER renders as failure (existing law) — it projects to `processing`/`dropped` per contract 07 §5. Additive; existing exports keep shapes.
3. **Error-reason registry** (new `packages/ux/src/error-reasons.ts`): the contract 07 §2 table as the single typed source — reason id, human label, technical trigger, next-action family. Exported for components + the §20 certification battery. Custom errors extend the registry; no inline free-text outside it.
4. **Command grammar** (`packages/ux/src/command-center.ts` extension): typed grammar for the six verbs `pay · request · invoice · link · convert · withdraw` (R2); a pure parse function `<verb> [counterparty] [amount] [asset] [modifiers]` → typed partial intent where missing parameters PRE-FILL (never a parse error); ambiguity model (disambiguation chips data); no-result → "create payment for '<q>'" intent-turn model. Pure logic, no UI, no network.
5. **Outcome-action reconciliation** (`packages/surface/src/outcomes.ts`): ADD aliases mapping the five certified outcome actions onto the command verbs + nav groups (`receive`≈request-lane, `move`≈withdraw/convert-lane). Do NOT rename `OutcomeActionId` or break the certified registry shape.
