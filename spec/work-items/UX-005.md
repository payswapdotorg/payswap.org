## Scope

Converge the topbar search + command palette onto the governing contract:
- `spec/experience/contracts/06-SEARCH-COMMAND-CONTRACT.md` (v1.1, incl. R2)

Deliverables:

1. **Topbar search field** (surgical addition to `command-center-shell.tsx`): visible **"/" kbd hint**; `/` focuses it from anywhere inside `/app` (suppressed while a text input is focused — same discipline as the CreateMenu chords); Esc restores prior focus. Placeholder rotates examples across both modes ("Search payments, customers… or type a command like 'pay 25 USDC'").
2. **Palette convergence onto the command grammar**: the palette's Commands group renders the six verbs `pay · request · invoice · link · convert · withdraw` and parses typed input through the UX-002 grammar (`@payswap/ux` command-center.ts parse function): `pay alice 100 usdc` → command=pay, counterparty=Alice (fuzzy contact match against honest data; else inline "Add contact 'alice'"), amount=100, asset=USDC. Missing parameters open the workflow form PRE-FILLED (never a parse error). Ambiguity → inline disambiguation chips (which Alice? which rail?) — never dead-ends. Targets: pay → `/app/payments?start=1` (W1), request → W1 request mode, invoice → `/app/billing`, link → `/app/payments/link` (W2), convert → `/app/convert`, withdraw → `/app/balances` withdraw flow.
3. **Resources group** (object search): Payments · Customers/Contacts · Settlements · Refunds · Products/Links — each row the object's list-cell renderer (masked IDs, StatusChip). Data honesty: payments search through the payments-plane (fixtures when enabled, API when configured, honest empty otherwise); other types render honest "not configured" states rather than fake results.
4. **Navigation group**: pages + settings sections, matched on title + synonyms.
5. **Zero-state** (no query): recents + "New payment" quick actions; recents persist per account LOCALLY (localStorage, never server).
6. **No-result state**: "No matches for '\<q\>'" + closest suggestions + **"Create payment for '\<q\>'?"** (the miss becomes an intent — routes to W1 pre-filled).
7. **Keyboard + a11y**: ↑↓ within group, ⇥ across groups, ⏎ execute; listbox semantics; selections announced to screen readers; keyboard-only end-to-end.
8. **Tests**: the contract 06 §6 battery — "/" focuses search on every authenticated page; six verbs parse and pre-fill (≥15 representative phrasings incl. missing-param and ambiguous cases); resource grouping; no-result intent-turn; keyboard-only walkthrough; honest search states.
