# W1-001 — Protocol Kernel + Persistence Contracts

Owner: Worker 1
Depends on: none
Parallel with: W2-001, W3-001

## Scope
Create provider-neutral protocol primitives:
- exact Money/Amount/Currency;
- identifiers and versioning;
- command/event envelopes;
- idempotency;
- deterministic state-machine framework;
- authoritative aggregate boundaries;
- PostgreSQL persistence conventions and migration rules;
- domain error taxonomy;
- deterministic clock/epoch abstraction.

Do not implement real rails.

## Acceptance
- exact money arithmetic;
- retry-safe idempotency;
- deterministic state transitions;
- tests preventing floating-point money;
- migration compatibility rules;
- provider SDKs cannot cross into domain packages.

## Forbidden
No mock settlement, fake balances, rail adapters or agent logic.
