# W2-001 — Trust, Agent and Capability Contracts

Owner: Worker 2
Depends on: none
Parallel with: W1-001, W3-001

## Scope
Define provider-neutral contracts for:
- Identity/Principal;
- AgentPrincipal;
- Mandate/PermissionGrant;
- AuthorizationRequest/Decision;
- AgentBody/AgentInstance;
- AgentPackage;
- Organization;
- Capability/AcceptanceCapability;
- Extension manifests;
- SecurityEpoch;
- Agent runtime;
- capability state vs source availability.

## Acceptance
- delegation attenuation testable;
- model/Soul replaceable without changing Body contract;
- agent proposals distinct from protocol commands;
- UNKNOWN capability semantics preserved;
- package/extension lifecycle explicit;
- proof/economic-accountability metadata available.

## Forbidden
No direct ledger access, direct rail execution, or model-specific financial authority.
