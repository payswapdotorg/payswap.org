# W2-003 — Capability Ecosystem and Acceptance

Owner: Worker 2
Depends on: W2-002, W1-002

Implement Capability Graph, provider/corridor registry, AcceptanceCapability, ServiceAccessCapability, smart-contract extension representation, PSP capability representation, extension/package lifecycle and certification integration.

Acceptance:
- source availability and capability state remain distinct;
- unreachable source becomes availability-unknown;
- capabilities carry proof/economic-accountability metadata;
- smart contracts declare code/address/admin/upgrade/oracle/custody properties and are searchable by the Lab after certification;
- ServiceAccessCapability can describe subscription/entitlement acquisition independently from funding;
- PSP capabilities are provider-neutral;
- retirement cannot rewrite history;
- merchant acceptance is queryable as a capability.
