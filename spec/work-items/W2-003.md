# W2-003 — Capability Ecosystem and Acceptance

Owner: Worker 2
Depends on: W2-002, W1-002

Implement Capability Graph, provider/corridor registry, AcceptanceCapability, extension/package lifecycle and certification integration.

Acceptance:
- source availability and capability state remain distinct;
- unreachable source becomes availability-unknown;
- capabilities carry proof/economic-accountability metadata;
- retirement cannot rewrite history;
- merchant acceptance is queryable as a capability.
