# W3-002 — Auth, Approvals and Developer API

Owner: Worker 3
Depends on: W3-001, W2-001

Implement real multi-tenant identity/session flows, signed approval artifacts, scoped execution grants and core REST/webhook surfaces.

Acceptance:
- out-of-scope action produces an approval request;
- approved action carries authorization lineage;
- revoked/expired authority fails closed;
- mutation endpoints are idempotent;
- evidence links are exposed by the API.
