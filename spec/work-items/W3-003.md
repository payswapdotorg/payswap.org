# W3-003 — Execution Graph and Provider Adapter Framework

Owner: Worker 3
Depends on: W3-002, W1-002

Implement canonical execution plan/attempt contracts, provider-neutral rail adapter interface, webhook ingestion and provider evidence preservation.

Acceptance:

- adapters cannot write financial state directly;
- UNKNOWN is preserved;
- provider evidence links to attempts;
- new providers can be added without domain rewrites.
