Owner: Worker 3
Depends on: W1-002, W2-003

Implement ParticipationGoal, experiments, IncentiveProgram, budget reservations, contribution records, reward formulas/accruals, referrals, recognition and leaderboard projections.

Acceptance:

- no unfunded reward can become final;
- attribution is reproducible;
- anti-gaming checks precede reward finalization;
- leaderboards cannot authorize;
- program changes create versions.
