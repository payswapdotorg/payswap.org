# W3-005 — Incentive Campaigns, Leaderboards and Referrals

Owner: Worker 3
Depends on: W3-004, W2-004

Implement production participation campaigns, attribution, dynamic target curves, role-specific leaderboards, referral surfaces and operator controls.

Acceptance:
- funding and caps are enforced;
- target curves are deterministic;
- wash/collusion signals can defer/suppress rewards;
- users can inspect reward provenance;
- leaderboards never render as universal trust/authorization scores.
