# W3-006 — Product UX and Messaging Adapters

Owner: Worker 3
Depends on: W3-005, W3-002

Build production UX for goals, intents, approvals, execution tracking, capabilities, incentives, disputes, evidence, participation and the Work Operating Plane. Add messaging adapters where allowed.

The primary UX is a universal Command Center with search, universal inbox, Work Graph context, projects/cases, agent collaboration and economic controls. Specialized incumbents remain visible through connector-backed context/action views when they remain systems of record.

Acceptance:
- no dead buttons;
- every visual state maps one-to-one to authority state;
- approval completes through a trusted surface;
- browser journeys use the same API/protocol path;
- major journeys can be completed from PaySwap as the main interface without requiring users to manually reconcile multiple systems;
- specialized external systems remain authoritative where required and their provenance is visible;
- UNKNOWN/error states are honest and actionable.
